**PSP Toolkit** — современная универсальная desktop-программа на Python для работы с собственными образами дисков, ресурсами и данными PlayStation Portable, а также подготовки игр PlayStation 1 для запуска на PSP.

Программа объединяет в одном окне функционал, для которого раньше требовалось несколько отдельных старых утилит (UMDGen, PSX2PSP, ciso, SFO Editor).

---

## ✨ Основные возможности

### 1. 📝 SFO Editor (Редактор метаданных)
* Чтение, просмотр и редактирование файлов `PARAM.SFO`.
* Строгая типизация и валидация данных (числа uint32, строки UTF-8 с нуль-терминатором).
* Добавление и удаление параметров без риска повредить бинарную структуру.
* Экспорт и сохранение байт-в-байт по официальной спецификации Sony.

### 2. 💿 ISO Editor & XMB Preview (Работа с образами PSP)
* Потоковый разбор файловой системы **ISO 9660** без загрузки гигабайтных файлов в оперативную память.
* Просмотр дерева файлов и папок с отображением размеров и секторов (LBA).
* Потоковое извлечение как отдельных файлов, так и целых директорий (или всей игры целиком).
* **PSP XMB Preview**: отображение родного фонового арта (`PIC1.PNG`) и иконки (`ICON0.PNG`) в пропорциях экрана консоли (16:9) с кнопками быстрого экспорта графики.
* **ISO Rebuilder**: замена файлов любого размера внутри образа с автоматическим пересчётом LBA и сборкой в новый ISO без риска для оригинального диска.

### 3. 🗜️ CSO Converter (Сжатие и распаковка)
* **ISO → CSO**: потоковое сжатие дисковых образов алгоритмом Deflate (`zlib`) с выбором степени компрессии (1–9).
* **CSO → ISO**: моментальная распаковка CSO обратно в полноразмерный образ.
* Поддержка спецификации CISO v1 (корректная обработка флага несжатых блоков для видео и звука).
* Подсчёт сэкономленного места на карте памяти и фоновая работа с плавным прогресс-баром.

### 4. 🕹️ PS1 to PSP EBOOT Builder (Классика PS1)
* Конвертация образов дисков PlayStation 1 (`.cue` / `.bin` / `.img`) в формат `EBOOT.PBP` для встроенного эмулятора PSP (POPS).
* Автоматическое сканирование `SYSTEM.CNF` и определение **Game ID** диска (`SLUS`, `SLES`, `SCES` и др.).
* Кастомизация иконки `ICON0.PNG` и фона `PIC1.PNG` с живым предпросмотром на экране XMB.
* Упаковка в блок `DATA.PSAR` по стандарту `PSISOIMG0000` с блочным сжатием по 37 632 байта (0x9300).

### 5. 🎨 Темы оформления
* **PlayStation Dark** — глубокий тёмный графитовый стиль с неоновыми акцентами PlayStation Blue (`#0070D1`).
* **PS1 Classic** — культовая серая текстурная тема в эстетике оригинальной консоли PlayStation 1 90-х годов.
* Переключение тем на лету через верхнее меню **«Вид» → «Тема оформления»**.

## 🚀 Как запустить программу

Перейдите в раздел [**Releases**](https://github.com/KatOriginal/psptoolkit/releases) справа и скачайте файл **`PSPToolkit.exe`**.  
Программа не требует установки Python и запускается в один клик.
