**UMD Studio** — современная универсальная desktop-программа на Python для работы с собственными образами дисков, ресурсами и данными PlayStation Portable, а также подготовки игр PlayStation 1 для запуска на PSP.

Программа объединяет в одном окне функционал, для которого раньше требовалось несколько отдельных старых утилит (UMDGen, PSX2PSP, ciso, PPF-O-Matic, SFO Editor).

---

## ✨ Основные модули

### 1. 💿 UMD Editor (Работа с образами PSP)
* Потоковый разбор файловой системы **ISO 9660** без загрузки гигабайтных файлов в оперативную память.
* Просмотр дерева файлов и папок с отображением реальных размеров и секторов (LBA).
* Потоковое извлечение отдельных файлов, папок или всей игры целиком.
* **PSP XMB Preview**: отображение родного фонового арта (`PIC1.PNG`) и иконки (`ICON0.PNG`) в пропорциях экрана консоли (16:9).
* Быстрая смена графики прямо под экраном XMB с мгновенным обновлением арта на виртуальной PSP.
* **ISO Rebuilder**: замена файлов любого размера внутри образа с автоматическим пересчётом секторов и безопасной сборкой в новый ISO.

### 2. 🗜️ UMD Convertor (Сжатие и распаковка)
* **ISO → CSO**: потоковое сжатие дисковых образов алгоритмом Deflate (`zlib`) с выбором степени компрессии (1–9).
* **CSO → ISO**: моментальная распаковка CSO обратно в полноразмерный образ.
* Поддержка спецификации CISO v1 (корректная обработка флага несжатых блоков для аудио и видео).
* Двухколоночный интерфейс со сплиттером и подробной статистикой сэкономленного места на карте памяти.

### 3. 🧩 UMD Patcher (Модификации и русификаторы)
* **Бинарные патчи (.ppf и .xdelta)**: поддержка стандартов PPF 1.0–3.0 и XDelta3 (VCDIFF) с автозагрузкой движка `xdelta3.exe`.
* **Умный патчинг системных файлов**: программа автоматически определяет микро-патчи для `EBOOT.BIN` и `BOOT.BIN`, извлекает их из ISO, патчит и пересобирает образ в один клик.
* **Режим совместимости (-n)**: обход ошибок контрольной суммы для разных версий дампов игры.
* **Пакеты модов из архивов**: автоматическая интеграция переводов из архивов `.7z`, `.zip`, `.rar` и папок (например, для перевода Persona 3 Portable).

### 4. 🕹️ PS1 Builder (Классика PS1 to PSP)
* Конвертация образов дисков PlayStation 1 (`.cue` / `.bin` / `.img`) в формат `EBOOT.PBP` для встроенного эмулятора PSP (POPS).
* Автоматическое сканирование `SYSTEM.CNF` и определение **Game ID** диска (`SLUS`, `SLES`, `SCES` и др.).
* Кастомизация иконки `ICON0.PNG` и фона `PIC1.PNG` с живым предпросмотром на экране XMB.
* Упаковка в блок `DATA.PSAR` по стандарту `PSISOIMG0000` с блочным сжатием по 37 632 байта (0x9300).

### 5. 🧰 Встроенный SFO Editor
* Вынесен в верхнее меню **«Инструменты» → «Редактор PARAM.SFO...»** для удобного редактирования сохранений (`SAVEDATA`) и homebrew-параметров без загромождения основных вкладок.

### 6. 🎨 Темы оформления
* **PlayStation Dark** — глубокий тёмный графитовый стиль с неоновыми акцентами PlayStation Blue (`#0070D1`).
* **PS1 Classic** — культовая серая текстурная тема в эстетике оригинальной консоли PlayStation 1 90-х годов.
* Переключение на лету через верхнее меню **«Вид» → «Тема оформления»**.
